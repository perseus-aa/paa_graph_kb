### 2. Perseus Object-Image Linking Fix 🔗
- **Problem:** Discovered that Perseus Objects and Images were not linked in the Linked Art graph. They existed as separate islands (`HumanMadeObject` vs `VisualItem`).
- **Investigation:** Found that `stg:accessionNumber` (Objects) and `stg:archiveNumber` (Images) did NOT match formats.
- **Solution:** Identified that `stg:perseusName` (Object) and `stg:imageName` (Image) DO match (37k+ matches).
- **Implementation:** Created `src/paa_graph_kb/resources/templates/25_link_perseus_images.rq`.
  - Links Object to VisualItem via `la:digitally_shown_by`.
  - Enables traversal from Object -> Visual Item -> IIIF Service.

### 3. IIIF Manifest Generation Tool 🖼️
- **Goal:** Generate IIIF Presentation API 3.0 manifests for Knowledge Base objects.
- **Implementation:** Created `src/paa_graph_kb/cli/iiif_manifest.py`.
- **Features:**
  - Handles both HAM (Object -> DigitalObject -> Service) and Perseus (Object -> VisualItem -> Service) paths.
  - **Smart Dimensions:** Automatically fetches `info.json` from the IIIF service if dimensions are missing in the graph (crucial for Perseus).
  - Generates valid IIIF v3 Manifests with Canvases, AnnotationPages, and Painting Annotations.
- **Usage:**
  ```bash
  python -m paa_graph_kb.cli.iiif_manifest https://aa.perseus.org/id/thing/{uuid} --output manifest.json
  ```
