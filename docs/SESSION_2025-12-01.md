- Linked Art patterns
- SPARQL CONSTRUCT templates

## Questions Answered This Session

**Q: Are we loading the CIDOC-CRM ontology?**
A: No (was not loaded). Fixed by running `make graphdb-load-ontology`. Now active with 5M inferred triples.

**Q: Should we use CIDOC-CRM or Linked Art ontology?**
A: CIDOC-CRM. Linked Art is an application profile/usage pattern built ON TOP of CIDOC-CRM, not a separate ontology. We need CIDOC-CRM for inferencing.

**Q: What is PeriodO and who uses it?**
A: PeriodO (http://perio.do) is a gazetteer of scholarly period definitions. Used by British Museum, Open Context, Portable Antiquities Scheme, ARIADNE, Pleiades, China Historical GIS. It preserves different scholarly opinions about period definitions rather than imposing one standard.

**Decision:** Not needed for this project currently (culture field too simple: just "Greek", "Greek?", "Greek or Etruscan").
